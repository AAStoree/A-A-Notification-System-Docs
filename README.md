# A&A Notification System

A lightweight and customizable notification system for FiveM servers, developed by **A&A Store**.

## Features

- Clean and modern notification interface
- Customizable notification settings
- Designed for FiveM roleplay servers
- Framework compatibility as specified in the product release
- Easy installation and configuration

## Requirements

Before installing, make sure you have:

- A working FiveM server
- The dependencies listed on the Tebex product page
- The downloaded A&A Notification System package

## Installation

1. Download **A&A Notification System** from the official A&A Store Tebex page.
2. Extract the downloaded ZIP file.
3. Place the resource folder in your server's `resources` directory.
4. Check the included configuration file and follow the instructions provided with the resource.
5. Add the resource to your `server.cfg` using the resource folder's actual name:

   ```cfg
   ensure aa_Notify
   ```

6. Restart your server or start the resource.
7. Test the notifications in-game.

**Important:** Use the exact resource name and installation instructions included in your downloaded package. Dependencies and framework setup may vary by version.

## Configuration

Configuration options depend on the version you downloaded. Refer to the included configuration file and package instructions.

## Troubleshooting

**Notifications do not appear**
- Check the server console for errors.
- Verify that the resource started successfully.
- Check that all required dependencies are installed.
- Review the configuration and resource name.

**Interface does not load**
- Check the client console for errors.
- Verify that the downloaded package contains all required interface files.
